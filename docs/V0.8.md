# v0.8 — Admin & Operations

This milestone adds the operations layer required to manage YD Play safely without turning virtual coins into money.

### Backend
- named admin authentication
- session revocation
- RBAC
- user search and moderation actions
- audited ledger adjustments
- referral config and fraud review
- moderation-report intake and review
- coin economy reporting
- push campaign storage/composer API
- audit-log API

### Admin web app
- responsive dark operations UI
- overview KPIs
- user operations
- referral configuration
- fraud queue
- moderation queue
- economy view
- push composer
- audit log

### Still intentionally excluded
- real-money transactions
- cash-out
- gambling/betting
- real-money prizes
- direct push-provider delivery
- ad network integration
