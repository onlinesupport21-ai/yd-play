# YD Play v0.9 — Engagement, Rankings, Notifications & Safety

## Engagement

- Missions support one-time, daily and weekly periods.
- Progress is driven only by server-observed validated events.
- Mission and achievement rewards are claim-based and use the balanced virtual-coin ledger.
- Each claim has a stable idempotency key so retries cannot duplicate coins.
- Default missions: first validated Pulse Grid completion, three daily completions, and a daily 1,000+ score challenge.
- Default achievements: first validated game, 1,500+ Pulse Grid score, and combo 10.

## Leaderboards

Pulse Grid ships with daily, weekly and all-time best-score leaderboards. Only authoritative validated game completion records are eligible. The client cannot submit leaderboard scores directly.

## Analytics

`POST /v1/analytics/events` accepts up to 50 authenticated events. Every item carries a client-generated event ID and is deduplicated per user. Analytics failures are deliberately non-blocking in the Flutter app.

Admin can inspect a 1–90 day event summary with event counts and unique users at `/v1/admin/analytics/events`.

## Notifications

Admin campaign dispatch always creates in-app inbox items for active users. External push is optional and provider-neutral:

- Push tokens are encrypted server-side with AES-256-GCM.
- `PUSH_TOKEN_ENCRYPTION_KEY` must decode to exactly 32 bytes.
- `PUSH_PROVIDER_URL` is an optional HTTPS bridge/provider endpoint.
- When no external provider is configured, push attempts are recorded as skipped rather than falsely marked delivered.
- Delivery attempts are retained in `push_deliveries`.

The Flutter v0.9 app includes the in-app inbox. Provider-specific mobile token acquisition (for example Firebase/APNs) is intentionally not bundled until provider credentials/config are selected.

## Safety & moderation

Users can submit reports from Profile → Safety & reports, view the status of their own reports, and report the current Signal Clash opponent directly from a room. A report never auto-bans a user; moderation actions remain admin-reviewed and audit logged.

## Compliance boundary

No deposits, cash-out, wagering, transferable balances, real-money prizes, or multiplayer coin rewards were added in v0.9.
