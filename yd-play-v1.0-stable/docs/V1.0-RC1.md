# YD Play v1.0.0-rc1

This release candidate freezes the first complete product slice: auth, virtual wallet,
referrals, anti-abuse, Pulse Grid, Signal Clash, missions, achievements, leaderboards,
notifications, reports, admin operations, analytics and Android client.

## RC1 shipping gates

1. Production API must use HTTPS and realtime must use WSS.
2. Release APK must not point to localhost, `10.0.2.2`, or placeholder hosts.
3. Production secrets must be unique random values and must not use repository defaults.
4. PostgreSQL migrations 001–006 must apply cleanly on a fresh database.
5. `/v1/health/live` and `/v1/health/ready` must return healthy before traffic is enabled.
6. Realtime `/health` must be healthy and Redis/PostgreSQL connectivity must be verified operationally.
7. Signed release APK checksum must be recorded.
8. Terms, Privacy Policy, Community Guidelines and age/region policy must be reviewed for the launch jurisdictions.
9. Penetration/security review and abuse testing must be completed before public release.
10. A committed dependency lockfile must pin the final Node dependency graph.
11. Backups and a restore drill must be completed before production data is considered durable.

## Product boundary

Virtual coins have no real-world value. No cash-out, deposits, wagering, real-money prizes
or gambling functionality exists in the v1.0 release candidate.
